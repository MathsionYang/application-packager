# Qt 安装包工坊实施计划

日期：2026-10-14。用户已确认“严格按照原型使用 Qt 开发”。

**Goal:** 交付与 HTML 原型对应的原生 Qt 桌面应用，接入实际路径、多个环境包、Inno 构建与记录。

**Architecture:** PySide6 原生 Qt Widgets，独立的配置/校验/存储层、纯 Python Inno 构建层、Qt 工作线程及界面层。总安装器内嵌环境包及三个独立子安装器。

**Tech Stack:** Python 3.13、PySide6-Essentials、Inno Setup 7、pytest、PyInstaller。

**Spec:** `../prototype/index.html`、`../prototype/styles.css`、`../prototype/app.js` 及 `../桌面软件统一安装包-需求分析与方案.md`。原型是界面依据，真实桌面行为替换演示路径与打包进度。

## 全局要求

- 原生 Qt 控件保留导航、三个软件输入、环境列表、输出、摘要、操作栏、日志、记录和设置。按后续确认删除说明性文字和整套安装预览。
- C/输出必填；A/B 可空；支持 EXE 主入口或完整发布目录；入口不唯一时要求选择。
- 环境包多选 EXE/MSI，去重、调整顺序、编辑安装参数。
- 构建真实子安装器及一个总包；运行环境先执行，失败停止；C 固定安装，A/B 可选。
- 三个软件各自 AppId、目录、快捷方式及卸载入口。总包不接管共享运行库卸载。
- 稳定配置与记录写入 LocalAppData，输入目录只读；输出与输入目录不能嵌套。
- 源目录索引、直接编译和取消在后台执行；取消仅清理当前任务中间产物。
- 不在开发电脑上实际安装运行库或用户程序。真实构建验证使用官方示例发布文件。
