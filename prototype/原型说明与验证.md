# 统一安装包工具 HTML 原型

**Goal:** 验证 Windows 桌面打包工具的布局、路径配置、多个运行环境安装包和安装选择流程。

**Architecture:** 纯 HTML/CSS/JavaScript、本地运行、无外部资源。打包和安装以明确标注的演示状态呈现，不访问发布目录，不编译或执行安装器。原型确认后才进入 Qt 桌面实现。

**Tech Stack:** HTML、CSS、原生 JavaScript；正式桌面应用采用 Qt，具体 Qt 绑定在正式开发时确定。

**Spec:** `../桌面软件统一安装包-需求分析与方案.md`，结合用户补充的运行环境安装包需求。

## 使用

直接双击本目录的 `index.html`，或者上一级目录的 `安装包工坊-原型.html`（已内嵌全部样式与脚本，可单独复制）。也可访问本地预览地址 `http://127.0.0.1:8765/`，服务运行期间有效。无需联网或安装前端依赖。

点击“加载完整示例”可体验完整流程：C + A + B，以及两个 VC++ 安装包。浏览按钮打开原型示例路径选择器，也可以直接填写 Windows 路径。原型不验证磁盘文件是否真实存在。

## 需求约束

- C 路径与输出目录必填；A/B 路径选填。
- 支持多个已有运行环境安装包，接受 EXE/MSI，支持增删、调整顺序及安装参数配置。
- 运行环境先于全部业务软件执行；环境失败时停止后续安装。
- C 必装，A/B 在最终安装界面中勾选；业务软件没有先后依赖。
- 三个软件各自独立安装、运行和卸载。
- VC++ 示例采用 `/install /quiet /norestart`；MSI 由后续 Qt/Inno 实现通过 `msiexec` 执行；其他 EXE 参数可配置，留空表示使用该安装包自身界面。
- 不生成实际 EXE，不执行任何安装，不开始 Qt 实现。

## 文件与执行步骤

- `index.html`：工作台、构建记录、设置、路径选择、安装预览等语义结构。
- `styles.css`：浅色桌面布局、组件状态、对话框和窄屏适配。
- `app.js`：表单、参数、运行环境列表、模拟构建、模拟安装、配置导入导出、构建记录。

## 验证场景

1. 空路径提交应显示 C 与输出目录的明确错误。
2. 加载完整示例后，包含 C/A/B 与两个 VC++ 安装包。
3. 运行环境可以多选添加、移除、排序及修改参数。
4. 模拟构建可开始、取消及完成，日志和构建记录反映实际演示状态。
5. 安装预览 C 不可取消，A/B 独立勾选；无 A/B 路径时不出现对应选项。
6. 安装预览先执行所有运行环境，再执行勾选的软件。
7. 环境失败场景应显示失败，业务软件保持未执行。
8. 页面和数据均标注为原型演示，不能误认为已真实生成安装包。
